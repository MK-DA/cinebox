# 🎬 CinéBox — Découverte de films

## Description

CinéBox est un site web qui permet aux utilisateurs de découvrir des films, de rechercher des titres et de consulter les informations principales de chaque film.

Le projet a été réalisé avec HTML, CSS et JavaScript, sans framework, dans le but de pratiquer les bases du développement web front-end.

## Fonctionnalités

- Affichage d'une galerie de films.
- Recherche de films par titre.
- Filtrage des films par genre.
- Affichage des détails d'un film dans une fenêtre modale.
- Affichage d'un message lorsqu'aucun film ne correspond à la recherche.
- Interface responsive adaptée aux ordinateurs, tablettes et téléphones.
- Affichage des affiches de films.

## Technologies utilisées

- **HTML5** : structure des pages.
- **CSS3** : mise en forme et design responsive.
- **JavaScript** : recherche, filtres et interactions.
- **Git et GitHub** : gestion du code source et hébergement du projet.
- **GitHub Pages** : publication du site web.

## Installation et utilisation

1. Clonez ou téléchargez le dépôt GitHub.
2. Ouvrez le dossier du projet.
3. Ouvrez le fichier `index.html` dans un navigateur web.

Aucune installation de dépendances n'est nécessaire.
